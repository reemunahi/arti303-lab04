TASK 1

1. ?- house = house.
true.

2. ?- house = abc.
false.

3. ?- edge(a,b) = edge(C,b).
C = a.

4. ?- edge(a,d) = edge(C,B).
C = a,
B = d.

5. ?- edge(C,B) = edge(a,d).
C = a,
B = d.

6. ?- edge(A,f(g,h)) = edge(a,B).
A = a,
B = f(g, h).

7. ?- edge(A,A) = edge(b,c).
false.

8. ?- edge(A,A) = edge(b,b).
A = b.

9. ?- A = B, B = f.
A = B, B = f.

10. ?- A = B, B = f, A = e.
false.

Explanations

1. Both sides are the same atom, so they unify.
2. house and abc are two different constants, and a constant unifies only with itself.
3. Same functor and arity. C takes the value a, and b = b.
4. Each variable unifies with the constant in its position: C = a, B = d.
5. Same as 4 with the sides swapped. Unification works in both directions.
6. A takes a, and B takes the whole structure f(g,h), since a variable can unify with any term.
7. A must be both b and c, which are different constants, so it fails.
8. Both positions need b, so A = b satisfies both.
9. A and B are linked, then B becomes f, so A is f as well.
10. After the first two goals A is f, and f = e fails because they are different constants.
