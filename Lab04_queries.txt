############################################################
TASK 1 - Unification queries
############################################################

------------------------------------------------------------
1. ?- house = house.
------------------------------------------------------------
true.

Why: Both sides are the same atom, so they unify.


------------------------------------------------------------
2. ?- house = abc.
------------------------------------------------------------
false.

Why: house and abc are two different constants. A constant
unifies only with itself.


------------------------------------------------------------
3. ?- edge(a,b) = edge(C,b).
------------------------------------------------------------
C = a.

Why: Same functor (edge) and same number of arguments (2).
C is a variable, so it takes the value a. The second
arguments, b and b, are identical.


------------------------------------------------------------
4. ?- edge(a,d) = edge(C,B).
------------------------------------------------------------
C = a,
B = d.

Why: Same functor and arity. Each variable unifies with the
constant in the matching position.


------------------------------------------------------------
5. ?- edge(C,B) = edge(a,d).
------------------------------------------------------------
C = a,
B = d.

Why: Same as query 4 with the sides swapped. Unification
works the same in both directions.


------------------------------------------------------------
6. ?- edge(A,f(g,h)) = edge(a,B).
------------------------------------------------------------
A = a,
B = f(g, h).

Why: A unifies with the constant a. B is a variable, and a
variable can unify with a whole structure, so B = f(g,h).


------------------------------------------------------------
7. ?- edge(A,A) = edge(b,c).
------------------------------------------------------------
false.

Why: The same variable A appears twice, so both positions
must hold the same value. A would need to be b and c at the
same time, and b and c are different constants.


------------------------------------------------------------
8. ?- edge(A,A) = edge(b,b).
------------------------------------------------------------
A = b.

Why: Both positions want the value b, so A = b satisfies
both of them.


------------------------------------------------------------
9. ?- A = B, B = f.
------------------------------------------------------------
A = B, B = f.

Why: A = B links the two variables. B = f then gives B the
value f, and because A is linked to B, A is f as well.


------------------------------------------------------------
10. ?- A = B, B = f, A = e.
------------------------------------------------------------
false.

Why: After the first two goals, A and B both hold f. The
third goal tries A = e, which means f = e. These are two
different constants, so it fails.


############################################################
TASK 2 - Family queries
############################################################

Facts used:
  male(ali).  male(ahmad).  male(muhammad).
  male(faisal).  male(hassan).  male(khan).
  female(sara).  female(nora).
  parent(ali, ahmad).  parent(ali, muhammad).
  parent(ahmad, sara).  parent(ahmad, nora).
  parent(ahmad, khan).  parent(muhammad, faisal).
  parent(faisal, hassan).


------------------------------------------------------------
1. Show the names of all females.
------------------------------------------------------------
?- female(X).
X = sara ;
X = nora.

Why: X is a blank. Prolog gives the first female, and ; asks
for the next one. There are only two females in the facts.


------------------------------------------------------------
2. Show whether there is any male.
------------------------------------------------------------
?- male(_).
true.

Why: The anonymous variable _ means "somebody, and I do not
care who". Prolog finds a male, so the answer is true.


------------------------------------------------------------
3. Show the grandparent of Faisal.
------------------------------------------------------------
?- parent(GP, P), parent(P, faisal).
GP = ali,
P = muhammad.

Why: The shared variable P must be a parent of faisal and
also a child of GP. The only parent of faisal is muhammad,
and muhammad's parent is ali, so ali is the grandparent.


------------------------------------------------------------
4. Show all daughters of Ahmad.
------------------------------------------------------------
?- parent(ahmad, D), female(D).
D = sara ;
D = nora.

Why: D must be a child of ahmad and also female. Ahmad's
children are sara, nora and khan, but khan is male, so only
sara and nora qualify.


------------------------------------------------------------
5. Show whether Ahmad and Muhammad have a common parent.
------------------------------------------------------------
?- parent(P, ahmad), parent(P, muhammad).
P = ali.

Why: The same P must be a parent of ahmad and of muhammad.
Ali is the parent of both, so they have a common parent.


------------------------------------------------------------
6. Show whether Khan is the brother of Nora.
------------------------------------------------------------
?- parent(P, khan), parent(P, nora), male(khan), khan \= nora.
P = ahmad.

Why: Khan and nora share the same parent P (ahmad), khan is
male, and khan \= nora makes sure they are two different
people. All four conditions hold, so khan is nora's brother.
